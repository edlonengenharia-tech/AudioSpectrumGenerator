PROBLEMA RESOLVIDO
------------------
O executável era criado, mas aparecia apenas uma janela em branco.

CAUSA
-----
O Vite estava gerando caminhos absolutos (/) para os arquivos,
mas o Electron precisa de caminhos relativos (./).


CORREÇÕES APLICADAS
-------------------
1. vite.config.js
   ✓ Adicionado: base: './'
   ✓ Agora gera caminhos relativos

2. electron-main.cjs
   ✓ Adicionados logs de debug
   ✓ Verificação de arquivos
   ✓ Tratamento de erros

3. Scripts atualizados
   ✓ build-electron-fixed.bat (build corrigido)
   ✓ test-electron.bat (modo debug)


COMO USAR AGORA
---------------

   build-electron-fixed.bat

   Este script:
   - Verifica dependências
   - Gera build com caminhos relativos
   - Cria executável
   - Mostra correções aplicadas


OPÇÃO 2: Teste em Desenvolvimento (Debug)

SE AINDA TIVER PROBLEMAS
-------------------------

1. Execute o teste em desenvolvimento:
   test-electron.bat

2. Verifique os logs no console:
   - "Carregando: C:\...\dist\index.html"
   - "ERRO: Arquivo não encontrado"
   - "Falha ao carregar: ..."

3. Verifique o dist/index.html:
   Abra no navegador. Se funcionar, o problema é no Electron.

4. Habilite o DevTools:
   No electron-main.cjs, descomente:
   win.webContents.openDevTools();
