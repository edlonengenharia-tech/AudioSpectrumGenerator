SOLUCAO RECOMENDADA: BUILD DIRETO COM CARGO
--------------------------------------------

Em vez de usar o Tauri CLI, use o Cargo diretamente:

PASSO 1: Abrir o terminal na pasta do projeto

PASSO 2: Executar o script automatizado:
   build-direto.bat

   OU manualmente:
   cd src-tauri
   cargo build --release

PASSO 3: O executavel sera gerado em:
   src-tauri\target\release\audio-spectrum-generator.exe

PASSO 4: Renomear o arquivo (opcional):
   De: audio-spectrum-generator.exe
   Para: Audio Spectrum Generator.exe


O QUE ESTE METODO FAZ
---------------------
- Compila o aplicativo Rust diretamente
- Gera um executavel Windows nativo
- Nao precisa do Tauri CLI funcionando
- Mais confiavel e rapido


ALTERNATIVA: DOWNGRADE PARA TAURI v1
-------------------------------------

Se preferir usar o Tauri CLI normalmente:

1. Desinstalar Tauri v2:
   npm uninstall @tauri-apps/cli @tauri-apps/api

2. Instalar Tauri v1:
   npm install --save-dev @tauri-apps/cli@1 @tauri-apps/api@1

3. Usar a configuracao do Tauri v1 (ja criei antes)

4. Executar:
   npm run tauri:build
