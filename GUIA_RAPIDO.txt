  COMO CRIAR O EXECUTAVEL - GUIA RAPIDO
================================================================

O QUE FOI CRIADO
----------------
Um icone personalizado para o Audio Spectrum Generator com:
- Gradiente roxo-azul
- Barras de equalizador coloridas
- Nota musical brilhante
- Design moderno e profissional


COMO EXECUTAR (METODO MAIS FACIL)
----------------------------------

Execute este comando:

   build-final.bat

Este script vai automaticamente:
✓ Gerar todos os icones necessarios
✓ Compilar o projeto com Tauri
✓ Criar o executavel portable


O QUE O SCRIPT FAZ
------------------
1. Executa generate-icons.js que cria:
   - icon.ico (com multiplos tamanhos: 16, 24, 32, 48, 64, 256)
   - 32x32.png
   - 128x128.png
   - 256x256.png
   - 512x512.png
   - 128x128@2x.png
   - icon.icns (para macOS)

2. Verifica se os icones foram criados

3. Executa cargo build --release

4. Abre a pasta do executavel (opcional)


ONDE ENCONTRAR O EXECUTAVEL
----------------------------
Apos o build, o executavel estara em:

   src-tauri\target\release\audio-spectrum-generator.exe

Este arquivo:
- E um executavel Windows nativo
- Pode ser copiado para qualquer computador
- Nao precisa de instalacao
- Nao precisa de Node.js, Rust ou outras dependencias
- Tamanho: ~5-10 MB


COMANDOS ALTERNATIVOS
---------------------
Se preferir fazer manualmente:

1. Gerar icones:
   node generate-icons.js

2. Fazer build:
   cd src-tauri
   cargo build --release


PERSONALIZAR O ICONE
--------------------
Se quiser mudar o design do icone:

1. Edite o arquivo: generate-icons.js
2. Modifique o SVG na variavel "svgIcon"
3. Execute: node generate-icons.js
4. Faca o build: cd src-tauri && cargo build --release


ERROS POSSIVEIS
---------------

ERRO: "node: command not found"
-> Node.js nao esta instalado
-> Instale: https://nodejs.org/

ERRO: "Cannot find module 'sharp'"
-> Execute: npm install sharp

ERRO: "rustc: command not found"
-> Rust nao esta instalado
-> Instale: https://rustup.rs/

ERRO: "cl.exe not found"
-> Visual Studio Build Tools nao esta instalado
-> Instale: https://visualstudio.microsoft.com/visual-cpp-build-tools/


RESUMO
------
Para criar o executavel portable AGORA:

   build-final.bat

Pronto! O executavel sera gerado automaticamente com o icone personalizado.
